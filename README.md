# Enterprise Windows Server Infrastructure

## Project Overview

This repository documents a series of practical Windows Server infrastructure projects completed in a virtual enterprise environment.

The work demonstrates the configuration and management of core enterprise services, including Active Directory Domain Services, DNS, IIS web hosting, remote access, security policies, and IP address management.

The repository is organised into three modules that reflect different areas of Windows Server administration and enterprise networking.

## Technologies Used

- Microsoft Windows Server 2019
- Active Directory Domain Services (AD DS)
- Domain Name System (DNS)
- Internet Information Services (IIS)
- Remote Access Services
- Group Policy
- Windows Server Manager
- PowerShell
- VirtualBox
- TCP/IP networking

## Skills Demonstrated

- Installing and configuring Windows Server roles
- Promoting a server to a Domain Controller
- Joining additional servers to a Windows domain
- Creating and managing organisational units
- Configuring DNS zones and records
- Hosting and resolving multiple websites
- Managing secure remote access
- Implementing company-wide security policies
- Monitoring and managing IP address usage
- Troubleshooting server and network connectivity

## Project Modules

### Module 1: Enterprise Active Directory and DNS

This module focuses on deploying Active Directory Domain Services and DNS on a Windows Server.

Key tasks included:

- Installing the AD DS and DNS roles
- Promoting the server to a Domain Controller
- Creating a Windows domain
- Joining another server to the domain
- Creating organisational units
- Managing domain users and resources
- Testing domain and DNS connectivity

### Module 2: Enterprise Web Hosting and DNS

This module focuses on Windows-based web hosting and DNS resolution.

Key tasks included:

- Configuring IIS
- Hosting multiple websites
- Creating and managing DNS records
- Testing website name resolution
- Configuring DNS filtering
- Configuring DNSSEC
- Configuring network communication between virtual machines

### Module 3: Enterprise Network and Server Management

This module focuses on the administration, security, and monitoring of enterprise Windows Server services.

Key tasks included:

- Configuring dynamic IP allocation for multiple departments
- Providing secure remote access for field agents
- Configuring secure file transfers
- Supporting internal email communication
- Implementing organisation-wide security policies
- Monitoring and managing IP address usage
